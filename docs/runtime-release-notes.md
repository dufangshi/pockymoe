Pictures in a DeepSeek Harness conversation no longer stop the turn.

- **Images for agents that do not take them**: an agent that does not accept
  inline images, such as the DeepSeek Harness, now receives an attached picture
  as a file it can open, instead of failing with "inline image prompts were not
  advertised by this connection". Agents that take images still see them inline.
- **Phone top bar** (Web, from 0.13.53 devices on): with the one-handed layout
  off, Git, isolation and other conversation tools are in the thread tools menu,
  so the bar no longer overflows.
